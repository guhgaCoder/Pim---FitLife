# Pim | FitLife
Projeto criado destinado ao Trabalho Acadêmico da Faculdade - PIM


🏋️ FitLife — Sistema de Gerenciamento de Academia

O FitLife é um projeto acadêmico desenvolvido para o PIM IV da Universidade Paulista (UNIP), com o objetivo de criar uma plataforma de gerenciamento de academias, facilitando o acompanhamento de treinos, a evolução dos alunos e a administração das atividades.


💻 Tecnologias utilizadas

- Backend: C# e ASP.NET Core 8

- Frontend: HTML, CSS e JavaScript

- API REST: comunicação entre os sistemas

- Banco de dados: SQLite provisório, com integração ao SQL Server planejada

- Mobile: aplicativo Android em Java e XML (em desenvolvimento)

- Acessibilidade: integração com VLibras e recursos de personalização visual

🚀 Funcionalidades

- Cadastro e login de usuários

- Visualização e gerenciamento de treinos

- Acompanhamento da evolução dos alunos

- Perfil do usuário

- Painel administrativo

- Recursos de acessibilidade e inclusão

  🔧 Status do projeto

Em desenvolvimento.

A aplicação Web possui uma versão funcional. As próximas etapas incluem a integração definitiva com o banco de dados SQL Server, o desenvolvimento do aplicativo Android e os testes de integração entre as plataformas.


🎓 Objetivo acadêmico

O projeto integra conhecimentos de desenvolvimento Web e Mobile, banco de dados, arquitetura de software, DevOps e responsabilidade social, buscando oferecer uma solução tecnológica moderna, acessível e inclusiva.
